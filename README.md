# Yandex Practicum Go CI/CD Final

Этот репозиторий — учебный итоговый проект, где основной фокус сделан на **изучении и закреплении CI/CD-практик** в GitHub Actions.

## Цель проекта

Главная цель — не разработка сложного продукта, а отработка полного цикла:

- автоматические проверки кода в CI;
- контроль качества через тесты и `go vet`;
- автоматическая сборка и публикация Docker-образа в CD;
- выпуск по тегам через GitHub Actions.

Приложение с трекером посылок используется как удобная практическая база для этих процессов.

## Что реализовано в CI/CD

В `.github/workflows/deploy.yml` настроен единый workflow:

1. **CI job (`test`)**
   - запуск unit-тестов: `GOOS=linux GOARCH=amd64 go test`
   - запуск статического анализа: `go vet ./...`

2. **CD job (`deploy`)**
   - выполняется только после успешного CI
   - запускается только для push тега (`refs/tags/*`)
   - логин в Docker Hub через secrets
   - сборка и публикация Docker-образа

Таким образом, проект демонстрирует базовый production-like пайплайн: **проверка → сборка → публикация**.

## Технологический стек

- **Go 1.25.5**
- **GitHub Actions** (CI/CD)
- **Docker** (сборка и публикация образа)
- - **SQLite** (`modernc.org/sqlite`)

## Локальная проверка

Для локального повторения CI-шагов:

```bash
go test ./...
go vet ./...
```

## О приложении (вторично по отношению к CI/CD)

В репозитории есть простое Go-приложение для работы с посылками (регистрация, получение, обновление, удаление), которое используется как учебный пример для практики автоматизации поставки.
